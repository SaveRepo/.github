## 简体中文

### 我们的初衷

**SaveRepo** 是一个致力于保存代码特定历史版本的 GitHub 组织。

代码仓库的拥有者可能出于各种原因，将原仓库设为私有，甚至将其删除。我们尊重原作者的决定，同时相信有价值的知识与技术值得被留存和传播。因此，在许可、法律及平台规则允许的范围内，我们会尽可能及时地 Fork 并保存相关仓库的特定版本，降低技术资料随仓库消失而难以获取的风险。

### 归档原则

- **尽可能及时留存：** 在条件允许时，通过 Fork 保存仓库在特定时间点的状态。
- **不修改代码：** SaveRepo 不对所保存仓库的代码进行任何修改，也不以维护者身份提供修复、更新或技术支持。
- **尊重原始权利：** 原项目的著作权、许可证及其他权利仍归相应权利人所有。归档不代表原作者对 SaveRepo 的认可，也不会授予使用者超出原许可证范围的权利。
- **遵守平台规则：** 归档方式和仓库可见性以适用法律、许可证及 GitHub 平台规则为前提。

### 不接受的内容

SaveRepo 不接受、收录或传播以下类别的内容：

- 儿童性虐待材料（CSAM）；
- 涉及恐怖主义或极端主义的内容；
- 涉及化学武器、生物武器、放射性武器或核武器的内容（CBRN）；
- 未经相关人员同意制作或传播的 AI 深度伪造内容。

### 高危安全漏洞：先收录，后可见

对于涉及**严重或致命网络安全漏洞**的披露材料、概念验证代码（PoC）及漏洞利用代码（EXP），我们采用延迟公开机制，以平衡技术留存与潜在滥用风险：

1. **先私有留存：** 在合规前提下，优先以**独立私有归档仓库**保存原始内容，不立即公开。由于 GitHub 不允许将公开仓库的原生 Fork 单独设为私有，此类内容不会通过公开 Fork 提前暴露。
2. **至少等待 90 天：** 以相关漏洞**首次公开披露之日**为起点，归档内容至少保持私有 90 天，仅限获授权的组织成员访问。
3. **到期复核后公开：** 满 90 天后，经安全与合规复核，确认符合适用法律及平台规则且不存在需要继续限制公开的风险时，才会转为公开；必要时将延长私有期或不予公开。

### 许可证与免责声明

**使用任何归档仓库前，请自行查阅并遵守原仓库的许可证，以及您所在地区的适用法律法规。** 您应自行承担访问、下载、使用、运行或再分发相关代码的责任。

SaveRepo 保存的仓库均按 **“AS IS”（按原样）** 提供，**不作任何明示或暗示的保证**，包括但不限于准确性、安全性、适用性或持续可用性。 SaveRepo 不对因使用者违反原仓库许可证或适用法律法规而产生的损失、争议或其他不良后果承担责任。

## English

### Why SaveRepo Exists

**SaveRepo** is a GitHub organization dedicated to preserving specific historical versions of code repositories.

Repository owners may choose to make their projects private or delete them for many different reasons. We respect those decisions while believing that valuable knowledge and technology deserve to be preserved and shared. Subject to applicable licenses, laws, and platform policies, we aim to fork and retain snapshots of relevant repositories as promptly as possible, reducing the risk of technical resources becoming inaccessible when their original repositories disappear.

### Archiving Principles

- **Timely preservation:** Whenever feasible, we fork repositories to preserve their state at a particular point in time.
- **No code modifications:** SaveRepo does not modify archived repository code or act as an upstream maintainer providing fixes, updates, or technical support.
- **Respect for original rights:** Copyrights, licenses, and other rights remain with their respective holders. Archiving does not imply endorsement by the original authors or grant any additional rights beyond the original license.
- **Compliance with platform rules:** Our archiving methods and repository visibility settings remain subject to applicable laws, licenses, and GitHub policies.

### Content We Do Not Accept

SaveRepo does not accept, archive, or distribute content involving:

- Child sexual abuse material (CSAM);
- Terrorism or extremism;
- Chemical, biological, radiological, or nuclear weapons (CBRN);
- Non-consensual AI-generated deepfakes.

### High-Severity Security Vulnerabilities: Archive First, Disclose Later

For disclosures, proof-of-concept code (PoC), and exploit code (EXP) associated with **high-severity or critical cybersecurity vulnerabilities**, we use delayed publication to balance preservation with the risk of misuse:

1. **Preserve privately first:** Where legally permitted, we initially store the original material in a **separate private archival repository**, without making it public. Because GitHub does not allow an ordinary fork of a public repository to be made private independently, we do not create a public fork that would prematurely expose such material.
2. **Wait at least 90 days:** The private period lasts for **at least 90 days from the vulnerability's initial public disclosure**, with access restricted to authorized organization members.
3. **Review before publication:** After the 90-day period, the archive may be made public only following a security and compliance review, subject to applicable laws and platform rules. Publication may be delayed further or withheld if material risks remain.
